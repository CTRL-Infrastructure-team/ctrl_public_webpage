# 活動報告の利用方法

## 活動報告の投稿

部の活動報告を [/report](https://home.tcu-ctrl.jp/report) とトップの News に載せることができます。投稿はログイン後の管理画面から行います。

1. [ログインページ](https://home.tcu-ctrl.jp/login) にアクセスする
2. 管理人から教えてもらったユーザ名とパスワードでログインする
3. 「活動報告投稿」を開く
4. タイトル・本文・画像 1 枚を指定して「投稿する」

画像は jpg / png / gif / webp、500KB 以下です。

## 活動報告の編集・削除

1. ログイン後、「活動報告管理」を開く
2. 自分の投稿だけが一覧に出ます。「編集する」で内容を直せます
3. 編集画面で画像を選び直さない場合は、既存画像が維持されます
4. 一覧から削除もできます
