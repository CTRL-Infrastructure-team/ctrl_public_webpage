# 作品投稿機能の利用方法

## 作品投稿

exe 化したゲームを zip にまとめたものを、サイトの作品一覧（[/progress](https://home.tcu-ctrl.jp/progress)）に載せることができます。投稿はログイン後の管理画面から行います。

1. [ログインページ](https://home.tcu-ctrl.jp/login) にアクセスする
2. 管理人から教えてもらったユーザ名とパスワードでログインする
3. 「作品投稿」を開く
4. タイトル・本文、トップ画像 1 枚、その他画像 2 枚、zip 1 つを指定して「投稿する」

制約:

- 画像は jpg / png / gif / webp（既存データには jfif もあります）、1 枚 500KB 以下
- ゲームファイルは zip、100MB 以下
- Twitter ID を載せる場合はチェックを入れる（ユーザ登録時の Twitter ID が使われます）

## 作品の編集・削除

1. ログイン後、「作品管理」を開く
2. 自分の投稿だけが一覧に出ます。「編集する」で内容を直せます
3. 編集画面で画像や zip を選び直さない場合は、既存ファイルが維持されます
4. 一覧から削除もできます。公開ページからも消えます
